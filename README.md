# Lettore PDF

App Android gratuita e leggera per leggere PDF. Nessuna pubblicità, nessun permesso, nessuna libreria esterna (usa il motore PDF integrato in Android).

- Scorrimento continuo, zoom con due dita e doppio tocco
- Apertura da "Apri con…" (file manager, browser, email)
- Ricorda ultimo file e pagina per ogni documento
- Vai alla pagina, modalità notte
- Tocco singolo: nasconde/mostra la barra

## Build
Carica su GitHub (branch `main`): GitHub Actions compila l'APK e lo pubblica in **Releases**.
Android 8.0+.
